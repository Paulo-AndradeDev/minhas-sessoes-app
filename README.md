# Política de Privacidade

## Minhas Sessões

O aplicativo **Minhas Sessões**, desenvolvido por **Paulo Andrade**, foi projetado para funcionar localmente no dispositivo do usuário.

Os registros inseridos no aplicativo não são enviados para servidores do desenvolvedor, não são comercializados e não são compartilhados automaticamente com terceiros.

## 1. Dados coletados

O **Minhas Sessões** não coleta dados pessoais do usuário para envio ao desenvolvedor.

O aplicativo não exige:

- criação de conta;
- cadastro;
- login;
- autenticação em servidor.

Também não coletamos:

- nome;
- telefone;
- endereço;
- documentos pessoais;
- localização;
- contatos;
- identificadores do dispositivo.

O aplicativo também não utiliza ferramentas de analytics, rastreamento comportamental ou publicidade.

## 2. Informações registradas no aplicativo

O usuário pode inserir voluntariamente informações relacionadas às suas sessões, visitas e atividades, como:

- nome da Loja;
- data da sessão;
- rito;
- potência;
- Oriente;
- cargo;
- grau;
- tipo de sessão;
- temas discutidos;
- anotações;
- valores informados pelo usuário;
- links;
- arquivos anexados pelo próprio usuário.

Essas informações são utilizadas exclusivamente para permitir as funcionalidades de registro, organização, consulta e gerenciamento oferecidas pelo aplicativo.

## 3. Armazenamento local

Os dados cadastrados no **Minhas Sessões** são armazenados **localmente no próprio dispositivo do usuário**.

O aplicativo não mantém banco de dados remoto e não transmite esses registros para servidores controlados pelo desenvolvedor.

A conservação desses dados depende, portanto, do próprio dispositivo e das cópias de segurança realizadas pelo usuário.

## 4. Arquivos e anexos

O aplicativo permite que o usuário selecione arquivos do próprio dispositivo para associá-los a uma sessão.

Esse acesso ocorre apenas quando o usuário inicia voluntariamente a ação de adicionar um anexo e escolhe o arquivo por meio dos recursos fornecidos pelo sistema Android.

O aplicativo não realiza varredura automática dos arquivos existentes no dispositivo.

Os arquivos selecionados ficam associados aos registros locais do aplicativo.

## 5. Compartilhamento

O aplicativo possui recursos que permitem ao próprio usuário compartilhar informações ou arquivos.

Esse compartilhamento ocorre **somente mediante uma ação iniciada pelo usuário**, utilizando os mecanismos de compartilhamento fornecidos pelo sistema Android.

O desenvolvedor não recebe cópias do conteúdo compartilhado.

Após o usuário escolher compartilhar determinado conteúdo com outro aplicativo ou serviço, o tratamento posterior dessas informações passa a estar sujeito às políticas de privacidade do serviço escolhido pelo próprio usuário.

## 6. Permissões do dispositivo

O **Minhas Sessões** não solicita acesso permanente a recursos sensíveis como:

- localização;
- contatos;
- microfone;
- câmera.

Para funcionalidades relacionadas à abertura, seleção ou compartilhamento de arquivos, o aplicativo utiliza os mecanismos próprios do sistema Android, sempre em resposta a uma ação do usuário.

## 7. Compartilhamento com terceiros

O **Minhas Sessões** não vende, aluga, comercializa ou compartilha automaticamente dados do usuário com empresas, organizações ou terceiros.

Também não utilizamos:

- redes de publicidade;
- plataformas de análise comportamental;
- sistemas de rastreamento de usuários.

## 8. Retenção e exclusão dos dados

Como os dados permanecem armazenados localmente no dispositivo, o próprio usuário possui controle sobre seus registros.

Registros e anexos podem ser excluídos utilizando as funcionalidades disponíveis no aplicativo.

Os dados locais também podem ser removidos:

- ao apagar os dados do aplicativo nas configurações do Android;
- ao desinstalar o aplicativo.

Como o desenvolvedor não recebe nem mantém esses registros em servidor próprio, não existe uma cópia remota desses dados para ser excluída pelo desenvolvedor.

## 9. Segurança

O aplicativo foi desenvolvido buscando limitar o acesso aos dados ao estritamente necessário para suas funcionalidades.

A segurança das informações armazenadas localmente também depende da proteção do próprio dispositivo, incluindo:

- bloqueio de tela;
- atualizações do sistema;
- proteção contra acesso não autorizado;
- demais medidas de segurança adotadas pelo usuário.

## 10. Crianças e adolescentes

O **Minhas Sessões** não foi desenvolvido especificamente para crianças e não possui funcionalidades destinadas à coleta de informações de menores.

## 11. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada quando novas funcionalidades forem adicionadas ao aplicativo ou quando forem necessárias adequações legais ou técnicas.

A versão mais recente estará disponível neste repositório e/ou na página oficial de Política de Privacidade do aplicativo.
